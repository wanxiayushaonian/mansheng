节点图配色最大的陷阱是「彩虹图」：每个标签一个色，结果谁都记不住谁是谁。

## 本站的纪律

- **颜色只编码一个维度**：节点类型（post/note/essay），标签交给过滤面板
- **ghost 节点无色**：虚线灰边、透明底，一眼可辨的「未写」状态
- **边只分两档**：link 实线蓝，tag 弱边虚线灰、透明度 0.3

```css
.gnode--ghost { border: 1px dashed #999; background: transparent; }
.edge--tag { stroke-dasharray: 2 4; opacity: 0.3; }
```

## 依据

人类工作记忆对颜色的区分上限约 4–6 类。尺寸编码 degree、颜色编码 type、位置编码语义（[[d3-force-布局]] 的产物），三个通道各司其职。[[知识图谱入门]] 的可视化部分也是这套思路。配色系统的源头约束还是 [[前端性能预算]]：不用图片纹理，纯 CSS。
