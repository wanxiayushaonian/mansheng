本站是纯静态产物：vite build + build.mjs 生成的 data/，随便哪个静态托管都能跑。

## 对比

- **GitHub Pages**：免费、Actions 一体化，缺点是缓存策略不可控
- **Cloudflare Pages**：全球边缘节点快，带宽几乎不限，构建限额大方

部署流水线就三步：

```bash
node build.mjs
npm run build
wrangler pages deploy dist
```

## 经验

- SPA 路由需要 `_redirects` 文件：`/* /index.html 200`
- 数据 JSON 设长缓存（带 hash 更好），HTML 不缓存
- 预览环境（PR 自动部署）对花园类站点意义不大，内容站点没有「功能回归」

更激进的方案是把部分页面挪到边缘渲染，见 [[边缘渲染实验]]。构建侧的优化见 [[vite-构建优化]]。
