维护一个 Markdown vault，几个 CLI 工具能省大量时间。

## 常用组合

```bash
# 找出没有入链的孤儿文章
rg -l '\[\[' vault/posts | sort | uniq -c

# 统计各标签使用频率
rg -o 'tags:.*' vault/posts | tr ',' '\n' | sort | uniq -c | sort -rn

# 按修改时间列出最近写的
ls -lt vault/posts/*.md | head
```

- **ripgrep**：找链接、找标签、找失效引用
- **fd**：比 find 语法友好
- **jq**：检查构建产物，如 `jq '.nodes | length' public/data/graph.json`

## 哲学

这些检查和 [[markdown-解析管线]] 做的事情部分重叠，但 CLI 的价值是「写作时随手可用」——不用等构建。复杂的分析还是交给 [[增量构建实践]] 里的脚本，CLI 只解决 80% 的即时问题。
